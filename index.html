세느루는 어떤 플랫폼인가요?

세느루(SAENRU)는 AI로 만든 웹사이트·웹앱을 공개하고 반응을 얻는 대한민국 AI 빌더 런칭 플랫폼입니다. 프로젝트 등록과 노출은 무료이며, GitHub 저장소를 함께 여는 오픈 런칭을 지향합니다. 직접 만들 시간이 없는 팀을 위한 제작 스튜디오와 AEO·GEO 컨설팅(saenru.com/ai)도 함께 운영합니다.

FAQ

자주 묻는 질문

프로젝트 출시에 비용이 드나요?
아니요, 출시와 노출은 무료입니다. 세느루는 빌더가 많아질수록 커지는 플랫폼이라, 진입 문턱을 만들지 않습니다.
어떤 프로젝트를 올릴 수 있나요?
AI를 활용해 만든 웹사이트·웹앱·자동화·봇이라면 무엇이든 환영합니다. 완성도보다 '실제로 돌아가는 링크'가 기준입니다. 초안 단계라면 '첫 박수' 무대부터 시작할 수 있습니다.
GitHub 공개가 필수인가요?
필수는 아니고 권장입니다. 저장소를 공개한 프로젝트는 '오픈 런칭' 배지를 달고 더 넓게 소개됩니다. 코드 공개가 어려우면 제작 과정 글로 대신할 수 있습니다.
제작을 맡기고 싶으면 어떻게 하나요?
세느루 스튜디오가 직접 만들어 드립니다. 웹사이트는 90만원부터(약 2주), 웹앱은 290만원부터(4–6주)이며, 완성물은 GitHub 저장소째 이관됩니다. 착수 전 범위와 금액을 서면으로 확정하고, 합의 없는 추가 비용은 없습니다.
AEO·GEO 컨설팅은 어디서 신청하나요?
전용 페이지 saenru.com/ai에서 안내합니다. ChatGPT·Gemini·Claude가 당신의 브랜드를 뭐라고 답하는지 확인하는 진단 리포트부터 시작할 수 있습니다.
